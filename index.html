Cómo trabajamos un sitio

  1. 1

    Me cuentas el negocio y me envías el contenido que tengas: carta, fotos, textos.

  2. 2

    Monto el sitio, lo pruebo en móvil y escritorio y genero el QR listo para imprimir.

  3. 3

    Publico, configuro Google Maps y te dejo una capacitación de 30 minutos para editarlo.

Incluye dominio, hosting y el QR impreso. Pago único, sin mensualidad por pedido.

Ingeniería y calidad

Cada entrega se prueba antes de publicarse

Trabajé varios años en aseguramiento de calidad de software. Antes de poner un sitio en producción corro pruebas automatizadas con Playwright en resoluciones de móvil y escritorio, reviso los tiempos de carga y dejo el código ordenado para poder mantenerlo.

Capa Herramienta Versión
Frontend HTML5 semántico · Tailwind CSS 3.4
Backend Python · FastAPI 3.12 · 0.115
Base de datos PostgreSQL 16
Pruebas E2E Playwright 1.48
Pruebas de API Pytest 8.3
Integración continua GitHub Actions —
Contenedores Docker 27

Pruebas en cada resolución

La suite de Playwright corre en viewport de móvil (390 px) y escritorio (1440 px) antes de cada publicación.

Presupuesto de peso

Cada página se mantiene bajo 150 KB. El pipeline falla si una entrega supera ese límite.

Datos de prueba versionados

Los fixtures viven en el repositorio y se revisan en cada cambio, no en una base aparte.

Código para mantener

Tipado, formateado y documentado para poder retomarlo meses después sin adivinar.
